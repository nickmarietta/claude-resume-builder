> Target employers: Tech companies, startups, health-tech

## S1: Role Profile & Priority Matrix

**Positioning:** Nick is a new-grad CS engineer with backend depth in Python (FastAPI, Flask), a Docker/containerization credential, mobile experience in SwiftUI, and an award-winning hackathon project. His stack spans Python backends, REST API design, PostgreSQL, Docker, GCP, and iOS — with enough frontend exposure (React contributions, SwiftUI ownership) to credibly claim full-stack breadth. Lead with the EcoNauts award as social proof, redClarity's Flask backend for API depth, EcoPrompt for backend scale + RAG, and Nuri for mobile differentiation. Frame as "backend-strong new grad who can contribute across the stack."

## S5: Cover Letter Guide

**Institution type:** Tech companies, health-tech startups, SaaS companies, product companies with Python/React stacks

**Opening hook patterns:**
- *Health-tech:* "From building a 7-endpoint Flask API that uses Gemini to explain medical lab results in four languages, to connecting a SwiftUI product browser to a skincare ingredient database for a team iOS app, I've spent the past year building backends and interfaces that make complex data accessible to real users."
- *Startup/general:* "I like problems where the backend is the hard part — which is why I own the FastAPI routing layer of an award-winning renewable energy app, the full Flask API for a medical document interpreter, and the RAG-powered backend for a hackathon AI tool that measured a 30% reduction in token usage."
- *Award-forward:* "My team won 1st place in the Sustainability category at FullyHacks 2025 — but my specific contribution was the FastAPI routing layer and Docker Compose configuration that made the ML models accessible to the React frontend."

**Key narrative thread:** "Backend engineer who ships" — show that Nick builds real, functional backends: an award-winning API layer (EcoNauts), a health-tech REST API (redClarity), a RAG backend with a measured result (EcoPrompt), and a mobile app logic layer (Nuri). The thread is: backend depth + delivery evidence, with enough breadth to contribute across the stack.

**"Why them" angle (what to research):**
- Their backend stack — Python/FastAPI/Flask → direct match; Express/Node → mention TypeScript + note
- Any mobile product — Nuri/SwiftUI is a differentiator
- Health-tech angle — redClarity is purpose-built for this
- Docker/cloud infra — EN-02 + GCP are the hooks

**Avoid:**
- Claiming to have "built the full product" for any team project
- Leading with AI/ML framing — save RC-02 (Gemini) and EP-01 (RAG) as supporting details, not the headline
- "contributed to" language that undersells — Nick fully owns each backend; only hedge on frontend contributions
- Mentioning SignalML — irrelevant for FS roles
