# Project: Language Learning Platform (LLP) — FullyHacks 2024

## Overview
A gamified language learning desktop application built with Python, using Pygame for interactive gameplay and audio feedback. Submitted to FullyHacks 2024 under the Education theme. Simulates a language learning game loop with menus, game modes, sound, and custom UI elements.

Built for FullyHacks 2024 — team of 3 (Nicklaus Marietta, YuHui Li, Matthew Marietta).

## Status
`hackathon` — submitted and demoed at FullyHacks 2024

## Tech Stack
- Python (100% of codebase)
- Pygame (game rendering, event loop, animations)
- tkinter (UI components)
- playsound (audio feedback module)
- Custom assets: fonts (Fighting Spirit, Blippo), background images, logo PNGs

## What Was Built
- Multi-screen game application: main menu → mode selection → gameplay
- Custom button system (`button.py`) for interactive menu navigation
- Audio integration for language learning feedback (playsound)
- Custom UI with branded fonts and image assets
- Game loop with Pygame event handling

## Key Technical Challenges
- Integrating Pygame with tkinter (two different UI paradigms) for different parts of the app
- Managing audio playback timing alongside the game loop without blocking frame rendering
- Designing a custom button component reusable across multiple screens
